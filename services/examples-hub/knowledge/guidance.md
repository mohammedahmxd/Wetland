# Capability example boundaries

All source records and policies in this package are invented demonstration fixtures. They are not WaterAid policy, donor requirements, programme achievements or real organisational lessons. Each response identifies its source records and package digest. Do not treat user-supplied declarations as independently verified evidence.

These read-only tools return facts, draft outlines, checklists and advisory decisions. They never approve grants or releases, change accounts, deploy software, send communications or produce approved final reports. Grant requirements marked covered mean a fixture mentions evidence; they do not establish eligibility. Missing evidence remains unknown.

Programme and communications outputs are unbranded draft material. Finished report/document generation must use the Brand-aware rendering pipeline with required Brand guidance and validation; these examples do not implement that renderer.

Edit the released config sources and guidance with the local studio, run tests, submit review, and deploy the approved version. Changing fixture figures should include updated expected-result tests. Real use requires authoritative policies, data connectors, permissions, privacy controls and tenant acceptance.
