# Wetland MCP marketplace

Serve `dist` with a static HTTP server, for example `python -m http.server 4317 --directory dist --bind 127.0.0.1`.

Edit `defaults` in `dist/app.js` to add or update curated tools. Each entry carries ownership, scope, status and capability information. The brand MCP is live; seven Water Care entries are concepts. Browser submissions and saved tools use localStorage and do not sync between people. Clear site storage to reset them. The JSON export contains the current filtered collection.

Original brand guidance snapshots are in `brand-reference`. Fonts and their licence are in `dist/assets`. The logo is original source artwork, with the upstream provenance recorded by `brand-reference/list_assets.json`.
